# Modern Library Resource Management System

*A PostgreSQL-Based Database for Multi-Branch Circulation, Resource Tracking and Fine Recovery*

### Created By
- Aditi
- Anshika Tiwari
- Kavya Gupta
- Ritik Vishwakarma

### Project Overview
This project develops a relational database management system for a multi-branch library using PostgreSQL. It focuses on managing library resources, book circulation, overdue loans, lost and unavailable book copies, and unrecovered fines.

### Project Components
1. Database design and table creation
2. Data import and validation
3. SQL queries for three problem statements
4. Transaction control operations
5. Database analysis and reporting

### Technology Used
- PostgreSQL
